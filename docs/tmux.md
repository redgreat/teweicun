  ---
  常用命令

  # 启动新会话（建议给个项目名）
  tmux new -s teweicun

  # 列出所有会话
  tmux ls

  # 重新接入会话
  tmux attach -t teweicun

  # 杀掉会话
  tmux kill-session -t teweicun

  # 重载配置（也可以在 tmux 里按 Ctrl+b r）
  tmux source-file ~/.tmux.conf

  ---
  推荐的开发布局
  
  进入项目后快速搭个三窗格布局：

  tmux new -s teweicun          # 创建会话
  # 在 tmux 里：
  Ctrl+b %   # 竖直切分 → 左边放前端
  Ctrl+b "   # 水平切分 → 右下放数据库/shell
  # 最终：
  # ┌──────────┬──────────┐
  # │ go run   │ npm run  │
  # │ server   │ dev      │
  # │          ├──────────┤
  # │          │ git/db/  │
  # │          │ 杂活     │
  # └──────────┴──────────┘

  要保存这个布局方便下次恢复，可以加装 tmux-resurrect 插件——改天想装的话告诉我就行。

# 创建会话
tmux new -s teweicun

# 临时退出会话
Ctrl+a b

# 切换到会话
tmux attach -t teweicun

# 竖直切分 → 左边放前端
Ctrl+a %   

# # 水平切分 → 右下放数据库/shell
Ctrl+a "

# 保存布局
Ctrl+a s

# 恢复布局
Ctrl+b r
tmux-resurrect
