### 1.2 数据流向说明

| 数据流向 | 说明 | 关键字段 |
|---------|------|---------|
| 基础数据 → 采购订单 | 物料、供应商数据 | material_id, supplier_id |
| 采购订单 → 入库单 | 订单明细到货 | purchase_order_id, arrived_quantity |
| 入库单 → 库存台账 | 确认入库增加库存 | batch_no, cert_id |

| 出库单 → 库存台账 | 确认出库减少库存 | quantity, locked_quantity |
| 库存台账 → 统计报表 | 实时库存查询 | total_quantity, total_value |

### 4.2 库存计算公式

```
库存数量 = 起始数量 + 入库数量 - 出库数量

可用数量 = 库存数量 - 锁定数量

库存金额 = 库存数量 × 单位成本

总库存金额 = Σ(各批次库存金额)
```

### 4.3 库存流水类型

| 流水类型 | 说明 | 数量符号 |
|---------|------|---------|
| in | 入库 | + (正数) |
| out | 出库 | - (负数) |
| lock | 锁定 | - (负数) |
| unlock | 解锁 | + (正数) |
| adjust | 调整 | ± (可正可负) |

## 7. 关键业务规则

### 7.1 入库规则

1. **批次号必填**: 每次入库必须指定批次号
2. **材质证明关联**: 特种材料必须关联材质证明,普通材料可选
3. **成本记录**: 建议每次入库都填写实际成本
4. **分批到货**: 一个采购订单可以多次入库
5. **数量控制**: 入库数量不能超过采购数量

### 7.2 出库规则

1. **库存检查**: 出库前检查库存是否充足
2. **先进先出**: 建议按批次号先进先出
3. **库存锁定**: 确认销售订单时锁定库存
4. **追溯信息**: 出库时保留批次与材质证明关联,保持追溯
5. **分批发货**: 一个销售订单可以多次出库

### 7.3 库存规则

1. **数量非负**: 库存数量不得为负数
2. **唯一约束**: 同一物料+仓库+批次+库位唯一
3. **金额计算**: 库存金额 = 数量 × 单位成本
4. **实时更新**: 入库/出库确认后立即更新库存

## 8. 与客户需求对应关系

| 客户需求 | 系统实现 | 流程节点 |
|---------|---------|---------|
| 材料入库清单 | 入库单管理 | 采购订单 → 入库单 → 库存 |
| 材料出库清单 | 出库单管理 | 销售订单 → 出库单 → 库存 |
| 材料编码自动生成 | fn_generate_material_code_new | 物料创建时 |
| 材质证明关联 | stock_in_item.cert_id / material_certificate.cert_no | 入库时关联 |
| 批次号自动生成 | fn_generate_batch_no | 入库时生成 |
| 库存统计 | v_inventory_summary视图 | 实时查询 |
| 库存金额计算 | 数量×单价 | 入库时记录成本 |
| 材料追溯 | 批次号+材质证明编号 | 全流程追溯 |

## 9. 系统优势

1. **流程清晰**: 采购→入库→库存→出库→销售,数据流转明确
2. **追溯完整**: 从材质证明到产品出库,全流程可追溯
3. **实时准确**: 库存数据实时更新,账实相符
4. **成本可控**: 入库记录成本,支持库存金额统计
5. **合规满足**: 满足特种设备行业追溯要求
