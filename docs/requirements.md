## 1. 项目概述

### 1.1 项目名称

**特维存（TeWeiCun）** — 特种设备专用进销存管理系统

### 1.2 项目定位

面向小型压力容器设备制造企业的轻量级进销存管理系统，聚焦物料的采购入库、库存管理、销售出库三大核心流程，同时满足特种设备行业的合规追溯要求。

### 1.3 目标用户

- 持有压力容器制造许可证（A2/C2/D级等）的小型制造企业
- 年产量在 50-500 台（套）级别
- 物料种类不超过 1000 种
- 员工规模 10-100 人

### 1.4 项目目标

| 目标维度 | 具体描述 |
|---------|---------|
| **核心目标** | 实现物料全生命周期的进销存管理，替代 Excel 手工台账 |
| **合规目标** | 满足 TSG 法规对材料追溯性的要求（质保体系中材料控制程序） |
| **效率目标** | 减少库管人员 50% 的重复性台账录入工作 |
| **数据目标** | 库存数据实时准确，账实相符率 ≥ 99% |

### 1.5 项目范围

**一期范围（MVP）**：
- 基础数据管理（物料、供应商、客户、仓库）
- 采购管理（采购申请 → 采购订单 → 到货入库 → 采购退货）
- 库存管理（入库、出库、调拨、盘点、库存预警）
- 销售管理（销售订单 → 发货出库 → 销售退货）
- 特种设备材料追溯（材质证明、批次管理）
- 基础报表与统计

**二期规划**：
- 合同管理模块
- 价格管理模块（采购价、销售价、历史价格）
- 财务模块（应收应付、对账）

**三期展望**：
- 质量证明书自动生成
- 定期检验提醒
- 移动端（PDA 扫码）

## 2. 业务背景

### 2.1 行业特点

压力容器制造行业属于特种设备制造领域，受国家市场监督管理总局监管，具有以下特点：

1. **强制许可制度**：制造单位须取得特种设备制造许可证方可从事生产
2. **材料管控严格**：主要受压元件材料必须具有材质证明书，且可追溯到炉批号
3. **质保体系要求**：须建立并运行质量保证体系，材料控制程序是核心程序之一
4. **监检制度**：产品制造过程需接受特种设备检验检测机构监督检验
5. **追溯性要求**：从原材料采购到成品交付，全流程可追溯

### 2.2 现有痛点

| 痛点 | 描述 | 影响 |
|-----|------|------|
| **手工台账** | 采用 Excel 或纸质台账管理物料，数据分散 | 信息孤岛，查询效率低 |
| **追溯困难** | 材质证明书纸质归档，查找耗时 | 监检时无法快速提供追溯记录 |
| **库存不准** | 账实不符，经常出现有账无物或有物无账 | 影响生产计划，或重复采购 |
| **缺乏预警** | 无法及时发现库存不足或积压 | 生产缺料停工或资金占用 |
| **材料代用混乱** | 材料代用无规范流程，缺乏审批记录 | 合规风险，影响产品质量 |

### 2.3 业务流程概览

```
采购流程：
  生产需求/库存预警 → 采购申请 → 审批 → 采购订单 → 供应商发货 
  → 到货检验（含材质证明核实）→ 入库 → 付款（二期）

库存管理：
  入库登记 → 库位管理 → 库存查询 → 库存预警 → 盘点 → 调拨

销售流程：
  客户订单 → 备货 → 出库 → 发货 → 签收确认 → 收款（二期）

材料追溯：
  材质证明书 → 入库批次 → 领料记录 → 产品材料清单 → 质量证明书
```

## 3. 术语与缩写

| 术语/缩写 | 全称 | 说明 |
|-----------|------|------|
| TSG | 特种设备安全技术规范 | 国家市场监管总局颁布的特种设备技术法规 |
| 固容规 | 固定式压力容器安全技术监察规程 | TSG 21，压力容器制造核心法规 |
| 材质证明书 | Material Test Certificate | 材料出厂质量证明文件，含化学成分、力学性能等 |

| NDE/NDT | 无损检测 | 射线(RT)、超声(UT)、渗透(PT)、磁粉(MT)等检测方式 |
| SKU | Stock Keeping Unit | 库存量单位，物料的最小管理单元 |
| BOM | Bill of Material | 物料清单，产品所需的材料及数量列表 |
| PDA | Personal Digital Assistant | 手持终端设备，用于扫码操作 |
| MTC | Material Test Certificate | 同材质证明书 |

## 5. 功能需求

### 5.1 基础数据管理

#### 5.1.1 物料管理

**物料分类体系**：

```
一级分类：
├── 原材料
│   ├── 板材（钢板、不锈钢板、复合板等）
│   ├── 管材（无缝钢管、焊接钢管等）
│   ├── 锻件（法兰、管板、封头锻坯等）
│   ├── 型材（角钢、槽钢、工字钢等）
│   └── 铸件
├── 焊接材料
│   ├── 焊条
│   ├── 焊丝
│   ├── 焊带
│   └── 焊剂/保护气体
├── 标准件/紧固件
│   ├── 螺栓/螺母
│   ├── 垫片（含密封垫片）
│   └── 其他紧固件
├── 外购件/外协件
│   ├── 封头
│   ├── 法兰
│   ├── 安全附件（安全阀、压力表、液位计等）
│   ├── 阀门
│   └── 仪表
├── 辅助材料
│   ├── 油漆/涂料
│   ├── 保温材料
│   └── 包装材料
└── 半成品/在制品
    ├── 下料件
    ├── 成型件
    └── 组件
```

**物料基本信息**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| 物料编码 | VARCHAR(30) | ✅ | 系统自动生成或手动录入，全局唯一 |
| 物料名称 | VARCHAR(100) | ✅ | 如"Q345R钢板" |
| 规格型号 | VARCHAR(200) | ✅ | 如"δ16×2000×6000" |
| 物料分类 | 关联分类表 | ✅ | 多级分类 |
| 材质/材料牌号 | VARCHAR(50) | 条件必填 | 受压元件材料必填，如"Q345R"、"S30408" |
| 标准号 | VARCHAR(50) | — | 材料标准，如"GB/T 713"、"NB/T 47008" |
| 计量单位 | 枚举 | ✅ | 件、kg、m、m²、套、组等 |
| 辅助计量单位 | 枚举 | — | 板材常以"张"和"kg"双单位管理 |
| 换算系数 | DECIMAL | — | 主/辅计量单位换算关系 |
| 是否受压元件材料 | BOOLEAN | ✅ | 影响材质证明书管理要求 |
| 是否需要复验 | BOOLEAN | — | 部分材料入库前需进行复验 |
| 安全库存量 | DECIMAL | — | 低于此值触发库存预警 |
| 最高库存量 | DECIMAL | — | 高于此值触发库存积压预警 |
| 默认仓库 | 关联仓库表 | — | 入库默认仓库 |
| 备注 | TEXT | — | 补充描述 |
| 状态 | 枚举 | ✅ | 启用/停用 |

**业务规则**：
- BR-M001：物料编码一经创建不可修改
- BR-M002：受压元件材料必须填写材质/材料牌号和标准号
- BR-M003：物料停用后不可新增入库和出库操作，但可查询历史记录
- BR-M004：物料编码建议规则：`分类码(2位) + 材质码(4位) + 序号(4位)`，如 `01-Q345-0001`

**材质证明书信息**：

| 字段 | 说明 |

| 录入人 | — |

- BR-MTC002：材质证明书一经确认不可修改，如需更正须走变更流程
- BR-MTC003：通过炉批号可追溯到所有使用该批材料的产品
- BR-MTC004：材质证明书归档保存期限不少于设备设计使用年限

#### 5.5.2 批次追溯

**正向追溯**：原材料 → 使用记录 → 产品
```
材质证明书(炉批号) → 入库批次 → 出库记录(领料单) → 产品编号/工程号
```

**反向追溯**：产品 → 材料来源
```
产品编号/工程号 → 领料记录 → 入库批次 → 炉批号 → 材质证明书 → 供应商
```

**业务规则**：
- BR-TR001：受压元件材料的每一次流转必须记录批次信息
- BR-TR002：系统须支持根据炉批号查询该批材料的所有使用去向
- BR-TR003：系统须支持根据产品编号查询所使用的全部材料及其材质证明

#### 5.5.3 焊材管理（特殊物料管理）

焊接材料在压力容器制造中有特殊的管理要求：

| 管理要求 | 说明 |
|---------|------|
| 分类存储 | 焊材须专库存放，防潮防污染 |
| 烘干管理 | 低氢焊条须按规定烘干后方可使用 |
| 领用回收 | 焊条/焊丝按定额领用，余料须回收 |
| 批次绑定 | 焊材批次须与焊接记录关联 |
| 有效期管理 | 焊材有保质期限，过期不得使用 |

> **注意**：一期可简化焊材管理，仅做基本的进销存 + 保质期预警，烘干记录和领用回收可在二期完善。

| 销售订单 | SO | SO20260411001 | SO + 年月日 + 3位序号 |
| 调拨单 | TF | TF20260411001 | TF + 年月日 + 3位序号 |
| 盘点单 | IC | IC20260411001 | IC + 年月日 + 3位序号 |
| 退货单(采购) | RPO | RPO20260411001 | RPO + 年月日 + 3位序号 |
| 退货单(销售) | RSO | RSO20260411001 | RSO + 年月日 + 3位序号 |

### 8.2 核心业务约束

1. **库存不可为负**：任何出库操作不得导致库存量小于零
2. **单据不可删除**：已确认/已审批的单据不可删除，只能作废
3. **追溯链完整**：受压元件材料从入库到出库的每一步必须有批次记录
4. **审计留痕**：所有对库存数据的修改必须记录操作人和时间
5. **数据精度**：金额保留 2 位小数，数量精度视物料类型而定（件类整数、重量类保留 3 位小数）

### 8.3 特种设备行业约束

1. 受压元件材料必须有材质证明书，且化学成分/力学性能符合相应标准
2. 材料代用须经设计部门确认并保留审批记录（一期简化处理）
3. 焊接材料须关注保质期和存储条件
4. 所有与质量相关的记录保存期限不少于设备设计使用年限（通常 ≥ 20年）
5. 数据须满足特种设备监管部门可能的核查要求

物料编码格式：XX-XXXX-XXXX（共 10 位）

  99 - 其他

第 3-6 位：材质/品种代码
  不同大类有不同的编码规则，例如：
  板材类：Q345 → Q345, S304 → S304（取材料牌号前4位）

第 7-10 位：顺序号
  0001 ~ 9999
